# 학생 한국어 진단평가 화면 계획

## 브랜치별 현황

| 확인한 버전 | 프론트엔드 | 백엔드 |
| --- | --- | --- |
| `main`의 `51c1a35` | 미완료 학생에게 ‘진단 화면은 아직 이 프론트엔드에 구현하지 않았습니다’ 안내 표시 | 진단 시작·답안·결과 API와 가상 70문항 제공 |
| `feat/korean-assessment`의 `d14fd87` | 학년군 선택, 문항 응시, 이어 풀기, 결과 조회 구현 | 첨부된 두 학년군 문항집, 학년군 고정, 서버 채점·결과 조회 구현 |

학생 `s_pending`으로 접속했을 때 보이는 화면은 실행 중인 프론트엔드의 브랜치에 따라 달라집니다. 진단평가 변경은 프론트엔드, 문항 자산, 백엔드가 들어 있는 같은 체크아웃에서 실행합니다.

## 화면 구현

1. **응시 시작과 재개**
   로그인 응답의 `nextAction=diagnostic`에 따라 진단으로 안내합니다. `GET /diagnostic`의 `availableGradeBands`가 새로 시작할 수 있는 학년군을 알려 줍니다. 응시 중이라면 학년군 선택을 생략하고 서버가 지정한 다음 문항을 가져옵니다. 예전 백엔드에 연결된 경우 같은 브랜치에서 백엔드를 다시 실행하라는 메시지를 표시합니다.
2. **문항 화면**
   첨부 이미지의 제목과 우측 문항 번호, 가로 진행 막대, 둥근 흰색 문항 카드, 번호 선지, 카드 밖 우측 버튼을 적용합니다. 진행 수치는 서버 문항 수를 사용합니다. 현재 각 학년군은 듣기 15문항, 읽기 20문항입니다. 문항 카드는 듣기·읽기와 교과를 함께 표시하고, 음원이 있는 문항에는 **듣기** 버튼을 제공합니다. 읽기 지문, 표, 그림 선지는 첨부 자산과 문항 데이터에 맞춰 표시합니다.
3. **답안과 결과**
   선지를 고르면 **다음** 버튼이 활성화됩니다. **모르겠어요**도 명시적으로 제출할 수 있습니다. 저장을 마친 뒤에만 다음 문항을 가져오며 실패할 경우 현재 선택과 다시 시도할 수 있는 안내를 유지합니다. 마지막 답안 제출 후 결과를 표시하고, 완료한 학생은 대시보드의 **진단 결과**에서 다시 확인합니다.
4. **브라우저 검증**
   두 학년군에서 듣기 재생·일시정지, 텍스트·그림 선지, 읽기 전환, 표 렌더링, 새로고침 후 재개 및 결과 조회를 확인합니다. 좁은 화면에서는 문항·선지·버튼이 가로로 잘리지 않아야 하며, 키보드로도 선지를 선택할 수 있어야 합니다.

## 백엔드 확인 범위

| 기능 | 계약 |
| --- | --- |
| 시작 | `POST /diagnostic/start`가 학생의 클래스 소속을 확인하고 학년군 문항집을 고정합니다. |
| 이어 풀기 | `GET /diagnostic/next-question`이 첫 미제출 문항과 진행 상태를 보냅니다. 정답은 응답에 포함하지 않습니다. |
| 제출 | `POST /diagnostic/answers`가 다음 문항의 답안 또는 `null`을 저장합니다. 같은 답안 재전송은 진행 수치를 늘리지 않습니다. |
| 결과 | `GET /diagnostic/results`가 완료된 학생의 듣기·읽기와 교과별 결과를 보냅니다. 교사는 소속 클래스 학생만 조회할 수 있습니다. |

현재는 메모리 모드이므로 브라우저 새로고침에는 진행 상태가 유지되지만 백엔드를 재시작하면 초기화됩니다.
