# 교사용 PDF 변환 병합 계획

## 유지할 흐름

교사가 PDF를 고르고 1~10쪽의 범위와 대상 학생을 선택합니다. PDF의 문단과 그림 위치를 분석해 기존 문단 위치에 쉬운 표현을 배치합니다. 읽기 수준과 모국어를 반영하고, 교과 개념어에는 쉬운 뜻과 번역을 제공합니다. 교사는 원본과 변환본을 비교한 뒤 수정, 승인, PDF 저장 또는 학생 배포를 선택합니다.

## 계층과 책임

1. **PDF 처리**. 첨부 PDF 제작 도구의 PDF.js 텍스트·도형 분석, 문단 묶기, 배경색 샘플링과 마스킹을 브라우저 모듈로 옮깁니다. PDF 저장에도 미리보기와 같은 지면 합성 결과를 사용하고 핵심어와 학습 도움말을 뒷쪽에 덧붙입니다. 원본에 넣기 어려운 긴 문장은 별도로 확인할 수 있게 표시합니다.
2. **FastAPI와 Solar**. 교사의 담당 교과와 학생의 진단 완료 여부를 확인합니다. 해당 학생의 읽기 수준과 언어에 맞춰 쉬운 표현과 개념어 뜻풀이를 만듭니다. 원본의 보존 규칙과 어휘 난이도 기준을 유지합니다. Solar Pro 4 요청과 응답 검증, 교사 키 암호화, 학생별 생성 상태와 초안 저장은 백엔드가 담당합니다.
3. **React 화면**. 기존 교사 자료 제작 메뉴와 디자인 컴포넌트로 파일 등록, 대상 선택, 원본·변환본 비교 화면을 구현합니다. 교사가 변환본을 수정하면 검토 상태를 해제합니다. 승인된 자료를 배포합니다.
4. **검증**. 가짜 Solar 응답으로 원본 PDF 분석, 초안 생성, 검토 및 DB 저장을 확인합니다. 다음 단계에서 발급된 Solar 키로 실제 모델 연결과 변환 품질을 확인합니다.

이번 변경은 PDF 변환 흐름을 대상으로 합니다.
